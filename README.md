# AURELIS — Watch Store

AURELIS is a modern and responsive watch e-commerce website built with React.

It features a curated collection of watches across different styles, with product search, category filtering, sorting, detailed product pages, and a shopping cart.

Users can select quantities, review their order, enter shipping details, and complete a simulated checkout process.

The website is designed with a clean, premium interface and a responsive layout for desktop, tablet, and mobile devices.
